# fiz_lab — физика зертханалық жұмыстарының стимуляциялары

Әр зертханалық жұмысқа арналған стимуляция (PhET, қазақ тілінде) — **сурет** (басқанда ашылады) және **QR-код** (телефонмен сканерлеу) түрінде.

Сайт сілтемесі (GitHub Pages қосылғаннан кейін):
**https://erkezha007-dotcom.github.io/fiz_lab/**

## 1. GitHub Pages қосу (бір рет)
Репозиторий → **Settings → Pages** → *Source*: `Deploy from a branch` → Branch: `main` (немесе осы тармақ), папка `/ (root)` → **Save**.
1–2 минуттан кейін жоғарыдағы сілтеме ашылады.

## 2. Google Sites ішіне қосу
Әр зертханалық жұмыстың бетінде мына үш тәсілдің бірін қолданыңыз:

**А) Карточка (сурет + QR + батырма) — ұсынылады**
Google Sites → **Кірістіру (Insert) → Енгізу (Embed) → URL бойынша** → сілтемені қойыңыз:
```
https://erkezha007-dotcom.github.io/fiz_lab/lab.html?id=pendulum
```
`id` мәні — төмендегі кестеден.

**Ә) Тек QR-код суреті**
`qr/` папкасындағы PNG-ні жүктеп алыңыз → Google Sites → **Кірістіру → Кескіндер → Жүктеп салу**.
Суретті таңдап, 🔗 (сілтеме) белгішесін басып, стимуляция сілтемесін қойыңыз — сонда суретті басқанда да ашылады.

**Б) Барлық жұмыстар бір бетте**
**Кірістіру → Енгізу → URL**: `https://erkezha007-dotcom.github.io/fiz_lab/`
